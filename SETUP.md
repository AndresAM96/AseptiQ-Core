# AseptiQ — Guía de instalación

## Requisitos previos

- **Node.js 20 LTS** o superior.
- **npm 10** o superior.
- Cuenta en [Supabase](https://supabase.com/).
- Editor recomendado: VS Code con extensiones:
  - ESLint
  - Prettier
  - Vitest

## 1. Clonar el repositorio

```bash
git clone <url-del-repo>
cd aseptiq
```
