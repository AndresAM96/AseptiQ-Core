# `src/shared/ui/` — Componentes visuales

Componentes reutilizables sin lógica de negocio. Ver `specs/06-ui-y-experiencia.md §4`.

## Componentes planificados

- `panel.js` — Card con header, acciones y toggle colapsable.
- `table.js` — Tabla con sort, búsqueda, paginación, responsive.
- `badge.js` — Badges de estado, stock, OP, prioridad, lote PT.
- `modal.js` — Stack de modales, apilables, cierre con Esc.
- `toast.js` — Notificaciones flotantes.
- `button.js` — Primario, secundario, ghost, danger, success, icon-only.
- `input.js` — Inputs con validación en vivo.
- `icons.js` — Sprite SVG + helper `icono()`.
